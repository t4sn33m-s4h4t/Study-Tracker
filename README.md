# Study Tracker

A simple study tracking application built with **React**, **Vite**, and **Tailwind CSS**. It helps students organize their admission preparation by tracking subjects, chapters, study hours, courses, and progress.

🌐 **Live Demo:** https://study-tracker-three-azure.vercel.app/today

## ✨ Features

- 📚 Track subjects and chapters
- 📊 Monitor study progress
- ⏱️ Log daily study hours
- 🎯 Create custom targets (Question Bank, Lectures, Notes, etc.)
- 🎓 Manage multiple coaching courses
- 🔗 Save course and discussion group links
- 🗓️ View all course routines in one place
- 📈 Visual charts for study and exam progress
- 🎨 Multiple color themes
- 💾 Local storage (No account required)

## 🛠️ Tech Stack

- React 18
- Vite
- Tailwind CSS v4
- React Router DOM
- Chart.js

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/t4sn33m-s4h4t/Study-Tracker.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📦 Build

```bash
npm run build
```

## 🚀 Deploy

```bash
npm install -g vercel
vercel --prod
```
